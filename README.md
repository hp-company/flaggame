# 국기 맞히기

42개국 국기로 즐기는 웹 퀴즈 게임입니다. 설치 없이 `index.html`을 브라우저로 열면 바로 실행됩니다.

## 모드
- **국기 보고 나라 맞히기**: 4지선다, 10문제
- **나라 보고 국기 맞히기**: 국기 4개 중 선택, 10문제
- **직접 써서 맞히기**: 나라 이름 입력, 첫 글자 힌트(0.5점), 다른 이름(튀르키예, 한국 등) 인정
- **60초 타임어택**: 오답 시 3초 감점
- **서바이벌**: 42개국 전부, 목숨 3개
- **국기 넘겨보기**: 국기 → 이름 순서로 자동 재생 (속도·순서 선택, ← → / 스페이스)
- **국기 도감**: 가나다순 목록, 이름 가리고 연습

## 효과음
Web Audio로 직접 합성한 효과음이 모드별로 다르게 나옵니다 (음원 파일 없음). 오른쪽 아래 버튼으로 켜고 끌 수 있고, 설정은 브라우저에 저장됩니다.
